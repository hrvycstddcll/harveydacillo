## ✦ About the Project

**Portfolio Website v1** is my first personal portfolio project.

Rather than creating a simple collection of projects, I wanted the website itself to demonstrate the things I'm learning and experimenting with — from frontend development and responsive design to animation and interaction.

The portfolio was built with a strong focus on:

* Modern UI/UX
* Responsive design
* Smooth animations
* Interactive components

This project also serves as a foundation for future versions of my portfolio as my skills and experience continue to grow.

## ✦ Animation

A major part of this project is the use of **GSAP** to create a more dynamic experience.

Animations are used for:

* Hero transitions
* Text reveals
* Staggered elements
* Scroll-based interactions
* Image transitions
* Blur effects
* Component entrances
* Interactive UI states

The goal isn't to animate everything, but to use motion where it improves the experience.

---

## ✦ Design Philosophy

The visual direction of the portfolio is based around a **modern, minimal, and masculine aesthetic**.

### Design Principles

**01 — Minimal**

Keep the interface clean and avoid unnecessary elements.

**02 — Visual Hierarchy**

Use typography, spacing, scale, and contrast to guide attention.

**03 — Motion**

Use animation to enhance interactions instead of distracting from content.

**04 — Responsive**

The experience should remain usable across different screen sizes.

**05 — Personality**

The portfolio should feel personal rather than looking like a generic template.

---

## ✦ Responsive Design

The website is designed to adapt across different screen sizes.

```text
Desktop
┌──────────────────────────────────────────────┐
│                                              │
│              FULL EXPERIENCE                 │
│                                              │
└──────────────────────────────────────────────┘

Tablet
┌──────────────────────────────┐
│                              │
│       ADAPTIVE LAYOUT        │
│                              │
└──────────────────────────────┘

Mobile
┌──────────────────┐
│                  │
│  MOBILE-FIRST    │
│    EXPERIENCE    │
│                  │
└──────────────────┘
```

Layouts, typography, spacing, navigation, and visual elements dynamically adapt to the available viewport.

## ✦ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hrvycstddcll/Portfolio-Website-v1.git
```

### 2. Navigate into the project

```bash
cd Portfolio-Website-v1
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.

---

## ✦ Build for Production

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
